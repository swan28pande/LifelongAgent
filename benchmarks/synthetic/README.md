# Synthetic preference-evolution benchmark

One user, 60 days of conversation, where preferences (drinks, exercise, meals, ...)
change on cycles and at specific transition points. The dataset is generated by
`scripts/generate_eval_dataset.py` and lives in `datasets/eval/`:

- `conversations.json`: the daily sessions
- `qa_pairs.json`: 67 questions, typed as factual, factual_evolving, recall,
  transition, pattern_id or prediction, and graded simple / medium / hard

## Files

| File | What it does |
|---|---|
| [run_v3.py](run_v3.py) | Runs memory_v3 over the dataset in three phases (ingest each day in order, build the summary hierarchy, answer every question) and scores with token F1 plus an LLM judge, by question type and difficulty. |

## Usage

```bash
venv/bin/python benchmarks/synthetic/run_v3.py                  # full 60 days, 67 questions
venv/bin/python benchmarks/synthetic/run_v3.py --days 10 --limit 15
venv/bin/python benchmarks/synthetic/run_v3.py --skip-ingest    # reuse the existing store
```

Output: `results/synthetic/<run>/` (default `v3`): `store/`, `ingest_stats.json`,
`memories.json`, `qa_results.json`. The inspector UI opens this store by default.

The older cross-system comparison on this dataset (memory_v2, NaiveRAG, RSum,
MemoryBank, MemGPT) is `evaluation/evaluate_synthetic.py`; its output is in
`results/legacy/complete_comparison/`.
