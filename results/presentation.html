Extracting, Consolidating, and Summarizing Multi-Domain Preference Oscillations Over Infinite Horizons

System Architecture & Comparative Evaluation
Challenges

The Problem Space

LLMs struggle with long-term retention of personalized user patterns and mathematical routines.

01 Context Window Decay

  • Standard context windows are finite and degrade performance on key retrieval tasks.
  • Retrieving complete historical dialogue logs is economically prohibitive over months.
  • Implicit dependencies, routines, and phase changes are buried inside noisy human conversational text.

02 Latent Mathematical Cycles

  • User preferences are rarely static; they fluctuate based on cycles (e.g., repeating N-day patterns) or calendar weeks (e.g., weekday/weekend schedules).
  • Standard memory stores capture atomic facts ("likes oat milk lattes") but miss temporal shifts ("latte on week 1, black coffee on week 2").
Prior Work

Current Baselines

Existing retrieval-augmented generation architectures fall short on temporal calculations.

✗ Standard Vector Database (RAG)

  • Retrieves isolated chunks semantically related to the query.
  • **Flaw:** Misses macro-chronological context and cannot perform mathematical cycle logic.
  • Retrieves specific statements but lacks structural transitions or time offsets.

✗ Long-Context Ingestion

  • Feeds the entire historical window directly into the LLM context.
  • **Flaw:** Suffers from "needle-in-a-haystack" retrieval failure in mid-range contexts.
  • Highly expensive, with token accumulation growing linearly/quadratically.
System Architecture

Methodology: Hierarchical Memory Store

Our proposed system decouples daily extraction, subject taxonomy, and hierarchical summarization.

⚡ Daily Extraction & Consolidation

  • **Daily Ingestion:** Extract preference subject/value pairs and SQL facts immediately after each conversation session.
  • **Taxonomy Alignment:** Dynamically consolidate granular subjects (e.g., 'latte', 'espresso') into high-level canonical domains ('drink') using LLM taxonomy engines.

📈 Hierarchical Summarization

  • **Weekly Summaries:** Groups daily preferences to calculate sequence transition durations.
  • **Monthly Summaries:** Merges weekly summaries to speculate on cycles (N-day or day-of-week).
  • **Yearly & Lifetime Profiles:** Confirms macro-rules and anchors to prevent context smoothing.

Future Scope

Limitations & Future Work

Identified weaknesses and design vectors for subsequent optimization.

⚠️ Flash-Lite Phase Accumulation Errors

  • Flash-Lite smoothed a shifting 6-day cycle into a 5-day cycle.
  • Over time, this off-by-one error causes complete prediction phase-inversion.
  • Requires explicit structured numeric tools (e.g., calculator or Python execution modules) for small models.

⚙️ Hybrid Pipeline Design

  • **Task Allocation:** Use Gemini Pro for the background mathematical extraction and hierarchical summarization (infrequent run).
  • Use Gemini Flash-Lite for fast, low-cost daily chat completions and semantic context construction.
