# related_papers

PDFs of the work this project builds on or compares with.

| File | Paper |
|---|---|
| `MemGPT.pdf` | MemGPT: Towards LLMs as Operating Systems (Packer et al., 2023): paged memory managed by the LLM. |
| `MemoryBank.pdf` | MemoryBank: Enhancing LLMs with Long-Term Memory (Zhong et al., 2023): memory with an Ebbinghaus forgetting curve. |
| `Recursively_Summarizing.pdf` | Recursively Summarizing Enables Long-Term Dialogue Memory (Wang et al., 2023): the RSum baseline. |
| `Mr_Rec.pdf` | MR.Rec: Synergizing Memory and Reasoning for Personalized Recommendation Assistant with LLMs (Huang et al., arXiv:2510.14629, 2025), the `baselines/MrRec/` system. |
| `survey.pdf` | Memory in the Age of AI Agents: A Survey (Hu et al., 2025). |

Also relevant, not stored here: LoCoMo (arXiv:2402.17753), the benchmark, and Mem0
(arXiv:2504.19413), the external baseline in `results/locomo/mem0/`.
