# Datasets

The synthetic preference-evolution dataset used by `benchmarks/synthetic/`. LoCoMo is
not here; it lives in `experiments/data/locomo10.json`.

| Folder | What it is |
|---|---|
| `eval/` | **Current dataset.** `conversations.json` holds one user's daily sessions over 60 days. `qa_pairs.json` holds 67 questions with type (factual, factual_evolving, recall, transition, pattern_id, prediction) and difficulty. `schedules.json` holds the ground-truth preference schedule the conversations were generated from. |
| `eval_gemini/` | An earlier, smaller version with the same three files (May 2026). Nothing in the code reads it. |
| `legacy/` | Earlier per-day datasets (`dataset_1`–`dataset_3`) used by memory_v2. |

Generated by `scripts/generate_eval_dataset.py`: every session covers all preference
domains, and preferences change on defined cycles and transition points, so the QA
answers can be checked against `schedules.json`.
